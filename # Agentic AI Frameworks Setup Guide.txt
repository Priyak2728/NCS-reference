# Agentic AI Frameworks Setup Guide

## Prerequisites

### Install Python 3.11

Verify:

```bash
python --version
```

Expected:

```text
Python 3.11.x
```

---

## Install Ollama

Download Ollama from:

https://ollama.com

Verify:

```bash
ollama --version
```

Pull a model:

```bash
ollama pull llama3
```

Verify:

```bash
ollama list
```

Expected:

```text
llama3
```

Start Ollama:

```bash
ollama serve
```

---

# Create Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

## Verify Ollama Connection

Create test.py

```python
from langchain_ollama import ChatOllama

llm = ChatOllama(model="llama3")

response = llm.invoke(
    "What is Agentic AI?"
)

print(response.content)
```

Run:

```bash
python test.py
```

If successful, your Ollama model is ready for LangChain, CrewAI, and LlamaIndex demos.
